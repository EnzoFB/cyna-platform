Guide utilisateur backoffice

Ce guide vous aide a utiliser le backoffice Cyna au quotidien. Il explique le role de chaque ecran et les gestes simples pour travailler rapidement, meme sans profil technique.

Il est organise selon le menu principal du backoffice. Vous pouvez lire le guide dans l ordre ou aller directement a la section qui correspond a votre besoin du moment.

Introduction

A quoi sert ce guide ?

Il vous accompagne pour realiser les actions essentielles dans le backoffice: suivi d activite, gestion du catalogue, animation commerciale, gestion des comptes et suivi des commandes.

Quand l utiliser ?

A l integration d un nouveau collaborateur, avant une action importante, ou quand vous voulez verifier une etape pour limiter les erreurs de saisie.

Comment lire ce guide efficacement ?

  • Commencez par la section qui correspond a votre tache immediate.
  • Lisez d abord "A quoi sert" puis "Quand l utiliser".
  • Suivez les etapes dans l ordre pour eviter les oublis.
  • Terminez par les points de vigilance avant validation.

Parcours recommande pour debuter

  1. Consultez le Dashboard pour comprendre la situation du jour.
  2. Mettez a jour Produits et Categories si necessaire.
  3. Verifiez les Promotions actives ou a venir.
  4. Controlez les Utilisateurs ayant acces au backoffice.
  5. Traitez en priorite les Commandes en attente.

Dashboard

A quoi sert cette fonctionnalite ?

Le Dashboard donne une vue claire de la performance: evolution des ventes, activite clients, progression par rapport aux objectifs et tendances generales de la periode.

Quand l utiliser ?

En debut de journee pour fixer les priorites, avant une reunion, pendant une campagne promotionnelle, ou en fin de semaine pour faire un bilan rapide.

Actions principales disponibles

  • Lire les indicateurs principaux de la periode en cours.
  • Comparer les resultats entre plusieurs periodes.
  • Identifier les produits qui tirent la performance.
  • Suivre la progression des objectifs.
  • Detecter rapidement une baisse ou un pic d activite.

Etapes simples pour l utiliser

  1. Ouvrir le menu Dashboard.
  2. Verifier les indicateurs globaux (tendance generale).
  3. Comparer les periodes pour identifier les ecarts.
  4. Analyser les produits les plus performants.
  5. Noter 2 a 3 priorites d action pour la journee.
  6. Partager ces priorites avec l equipe si necessaire.

Points de vigilance

  • Ne jugez pas un resultat sur une seule journee.
  • Comparez toujours une periode equivalente.
  • Verifiez le contexte (promotion, saison, evenement).
  • Distinguez signal ponctuel et tendance durable.

Produits

A quoi sert cette fonctionnalite ?

La section Produits permet de maintenir un catalogue propre et fiable: creation, mise a jour, activation ou retrait des produits selon vos besoins.

Quand l utiliser ?

Lors d un lancement, d un ajustement de prix, d une correction d information, d un changement de disponibilite, ou pour preparer une operation commerciale.

Actions principales disponibles

  • Ajouter un nouveau produit au catalogue.
  • Modifier un produit existant.
  • Associer le produit a la bonne categorie.
  • Mettre a jour les informations visibles.
  • Activer ou desactiver un produit.

Etapes simples pour l utiliser

  1. Ouvrir le menu Produits.
  2. Rechercher le produit ou cliquer sur Ajouter.
  3. Renseigner les informations essentielles.
  4. Verifier la categorie et le statut du produit.
  5. Enregistrer les modifications.
  6. Relire la ligne du produit dans la liste apres sauvegarde.

Points de vigilance

  • Utilisez des noms clairs et coherents.
  • Verifiez le prix avant validation.
  • Evitez les doublons de produits similaires.
  • Confirmez le bon statut (actif ou non actif).

Categories

A quoi sert cette fonctionnalite ?

Les Categories organisent le catalogue pour faciliter la recherche, la lisibilite des produits et la coherence globale de l offre.

Quand l utiliser ?

Quand une nouvelle famille de produits apparait, quand une categorie est mal nommee, ou quand la structure actuelle n est plus assez claire pour les equipes.

Actions principales disponibles

  • Creer une nouvelle categorie.
  • Renommer une categorie existante.
  • Mettre a jour sa description.
  • Verifier la bonne repartition des produits.
  • Supprimer une categorie devenue inutile.

Etapes simples pour l utiliser

  1. Ouvrir le menu Categories.
  2. Creer ou selectionner la categorie a modifier.
  3. Mettre a jour les informations utiles.
  4. Enregistrer la categorie.
  5. Verifier que les produits sont classes au bon endroit.
  6. Corriger les produits mal rattaches si necessaire.

Points de vigilance

  • Evitez les categories trop proches entre elles.
  • Gardez des intitules courts et explicites.
  • Supprimez seulement apres verification des produits lies.
  • Conservez une logique stable dans le temps.

Promotions

A quoi sert cette fonctionnalite ?

La section Promotions sert a planifier et piloter les offres commerciales pour dynamiser les ventes sur une periode precise.

Quand l utiliser ?

Pour une campagne saisonniere, un lancement de produit, une operation ponctuelle, ou pour soutenir une periode plus calme.

Actions principales disponibles

  • Creer une promotion.
  • Definir sa periode d application.
  • Ajuster ses conditions selon l objectif commercial.
  • Activer, suspendre ou arreter une promotion.
  • Verifier son etat avant diffusion.

Etapes simples pour l utiliser

  1. Ouvrir le menu Promotions.
  2. Cliquer sur Ajouter.
  3. Saisir le nom de la campagne et la periode.
  4. Renseigner les regles de l offre.
  5. Verifier le statut avant activation.
  6. Suivre la promotion pendant toute sa duree.

Points de vigilance

  • Controlez les dates de debut et de fin.
  • Evitez les offres qui se chevauchent sans verification.
  • Assurez-vous que la promotion reste comprehensible.
  • Arretez les promotions terminees pour garder une vue claire.

Utilisateurs

A quoi sert cette fonctionnalite ?

Cette section centralise la gestion des acces au backoffice: creation de compte, mise a jour des informations et gestion des roles.

Quand l utiliser ?

Lors de l arrivee d un nouveau membre, d un changement de mission, d une absence prolongee, ou quand un acces doit etre ajuste.

Actions principales disponibles

  • Ajouter un nouvel utilisateur.
  • Modifier les informations d un compte.
  • Mettre a jour le role attribue.
  • Activer ou desactiver un acces.
  • Verifier la liste des comptes existants.

Etapes simples pour l utiliser

  1. Ouvrir le menu Utilisateurs.
  2. Rechercher la personne ou cliquer sur Ajouter.
  3. Renseigner les informations requises.
  4. Attribuer le role adapte au besoin reel.
  5. Enregistrer les changements.
  6. Verifier que le compte apparait avec le bon statut.

Points de vigilance

  • Attribuez uniquement le niveau d acces necessaire.
  • Desactivez rapidement les acces non utilises.
  • Evitez les comptes en doublon pour une meme personne.
  • Relisez les roles avant validation finale.

Commandes

A quoi sert cette fonctionnalite ?

La section Commandes permet de suivre tout le cycle de traitement: consultation, verification du statut, suivi des details et actions de traitement.

Quand l utiliser ?

Pour traiter les commandes du jour, repondre a une demande client, verifier une anomalie, ou prioriser les dossiers urgents.

Actions principales disponibles

  • Consulter la liste des commandes.
  • Filtrer les commandes par statut.
  • Rechercher une commande specifique.
  • Ouvrir le detail pour verifier les informations.
  • Mettre a jour le suivi selon la situation.

Etapes simples pour l utiliser

  1. Ouvrir le menu Commandes.
  2. Filtrer les commandes pour prioriser le traitement.
  3. Ouvrir la commande concernee.
  4. Verifier les informations client et le statut courant.
  5. Effectuer l action necessaire.
  6. Confirmer que le statut final est bien mis a jour.

Points de vigilance

  • Traitez d abord les commandes les plus urgentes.
  • Verifiez deux fois avant toute action irreversible.
  • Conservez un suivi regulier des statuts en attente.
  • Assurez-vous que chaque action est bien confirmee.
